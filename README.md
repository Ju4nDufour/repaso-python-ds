# Práctica de Python: análisis básico

Este proyecto es una práctica sencilla de Python para repasar conceptos básicos de programación.

## Contenido

- Variables con tipos de datos nativos (`str`, `float`, `int`, `bool`)
- Uso de f-strings para formatear mensajes
- Estructuras de control como `if` y `for`
- Uso de listas y diccionarios para manejar datos
- Funciones con retorno de diccionarios
- Ejemplos de impresión por consola

## Cómo ejecutar

Desde la terminal, ubícate en la carpeta del proyecto y ejecuta:

```bash
python analisis_basico.py
```

Si `python` no está disponible en tu sistema, prueba:

```bash
py analisis_basico.py
```

## Objetivo

Comprender y practicar los fundamentos de Python mediante un ejemplo de gestión de productos y análisis de precios.
